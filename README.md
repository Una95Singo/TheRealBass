# Low Book

One-page, Real Book-style gig charts for bass: chords over slashes, boxed
rehearsal letters, a form roadmap with bar counts and confidence marks,
key/tempo/feel, bass notes and a Nashville key. No lyrics, no melody, no
note-for-note line.

This repository is being rebuilt from the earlier note-for-note transcription
experiment (TheRealBass). That code is preserved at the git tag
`v0-transcriber`; see `PLAN.md` for the pivot, the architecture and the phases,
and `DECISIONS.md` for the calls made along the way.
