# Baselines

Generated by `npm run baseline -w @lowbook/charts` from `reference/bcg-band-bass-charts.html`
using the app's abcjs build and font files. `<id>-staff.png` is what the parity test
compares against; `<id>-sheet.png` is for eyeballing only. Regenerate when abcjs, the
fonts or the render options change, and look at the diff before committing.
